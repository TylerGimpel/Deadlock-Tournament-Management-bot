Deadlock Tournament Management Bot Setup Wizard

Fills in this spreadsheet's side of the install guide's Part 2.

This walks through everything under Extensions > Apps Script > Project Settings > Script Properties, plus deploying this project as a Web App - the same things Part 2 of the install guide has you do by hand, just with inline validation and live connection tests.

If you don't have a piece of information yet (an API key, a Worker URL), every step has a Skip link - nothing here can get you stuck. You can always reopen this from Deadlock Tournament Management Bot > Setup Wizard later to pick up where you left off.

Before you start, Part 1 of the install guide (the Discord bot) should be done, and Part 2's installer should already be running, paused, and waiting for two values this wizard will generate for you. If you haven't started that yet, go do that first - it'll send you here at the right moment.

Deploy the Web App

Guide step 2.3

This one step has to be done by hand - a script can't authorize its own first deployment. Open the Apps Script editor (this stays open in its own tab, so you can switch back here without losing your place):

  1. Click Deploy (top right) → New deployment.
  2. Gear icon next to "Select type" → Web app.
  3. Execute as Me, Who has access Anyone.
  4. Click Deploy, authorize if asked.

Once that's deployed, this sheet can read its own Web app URL back from Apps Script - click Auto-detect rather than copy-pasting it by hand.

Connect Cloudflare

Guide steps 2.3 & 2.6

Your Worker needs to know these two values as Secrets named SHEET_WEBHOOK_URL and SHEET_WEBHOOK_SECRET. The secret is generated automatically below - no need to invent one. If you're using the installer, don't click Next yet - copy all three values below, switch to install guide step 2.4 to give them to the installer, and come back here afterward to check the box and continue. If you set up the Worker by hand instead, add the first two now: Worker → Settings → Variables and Secrets → add each one as a Secret, then check the box and continue.

The installer doesn't need this to set up Cloudflare - paste it in anyway when asked. It saves you looking it up again if you ever run the upgrade tool later.
